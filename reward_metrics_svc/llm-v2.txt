LLM Specifications

1. Overview

This microservice computes a scalar reward ∈ [-1.0, 1.0] for Reinforcement Learning (PPO loop) by comparing:

- Ground Truth ICD-10 codes (gt_codes)
- Enhanced ICD-10 codes (enh_codes)
- Original ICD-10 codes (org_codes)

The reward is improvement-based and hybrid, measuring whether enhanced codes are closer to ground truth than original codes, while also incorporating correctness and structural validity.

2. Core Design Philosophy

The system is divided into two layers:

2.1 Distance Layer
distance_between(gt, pred) → structured semantic distance ∈ [0,1]

2.2 Reward Layer (Hybrid v2)
R_total = tanh(w_tree * (D_org - D_enh)
    + w_exact * R_exact
    + w_structure * R_structure
)

This ensures:
- Smooth gradients for PPO
- Hierarchy-aware learning
- Strong correctness signal
- Robust handling of malformed outputs

3. Inputs

3.1 ICD-10 Tree Structure
- Preloaded in-memory
- Built from official ICD hierarchy
- Pruned using dataset codes
- Contains:
    - parent_map: Dict[str, str]
    - depth_map: Dict[str, int]
- Precompute:
    - max_depth = max(depth_map.values())

6. Code-Level Similarity (Wu-Palmer)

6.1 depth(code):

depth(code) = number of edges from ROOT to node

- Precomputed using BFS
- Stored in depth_map

Fallback:
- If code not found:
    infer using string heuristic

6.2 LCA(code_a, code_b)

Lowest Common Ancestor using parent_map

Algorithm:

ancestors_a = set()
curr = code_a
while curr exists:
    ancestors_a.add(curr)
    curr = parent_map[curr]

curr = code_b
while curr not in ancestors_a:
    curr = parent_map[curr]

return curr

6.3 Wu-Palmer Similarity

sim(a, b) = 2 * depth(LCA(a,b)) / (depth(a) + depth(b))
distance(a, b) = 1 - sim(a, b)

7. Set-to-Set Distance

Handles edge cases:
- If pred empty -> return 1.0
- If gt empty -> return 0.0
- If both empty -> return 0.0

D_set = (D_gt->pred + D_pred->gt) / 2

D_gt->pred = avg(min distance(gt_i, pred_j))
D_pred->gt = avg(min distance(pred_j, gt_i))

8. Coverage Penalty (GT -> Pred)

For each gt_i:
- coverage_score = max sim(gt_i, pred_j)
- weight = depth(gt_i) / max_depth
- penalty(gt_i) = weight * (1 - coverage_score)

P_cov = avg over all gt_i

9. Extra Codes Penalty (Pred -> GT)

For each pred_j:
- match_score = max sim(pred_j, gt_i)
- weight = 1 - (depth(pred_j) / max_depth)
- penalty(pred_j) = weight * (1 - match_score)

P_extra = avg over all pred_j
P_extra_final = λ_extra * P_extra

λ_extra ∈ [0.3, 0.5]

10. Cardinality Penalty

n_gt = len(gt_codes)
n_pred = len(pred_codes)

If n_gt == 0:
    return 0

- P_card = |n_pred - n_gt| / n_gt
- P_card_norm = min(1, P_card)
- P_card_final = λ_card * P_card_norm

λ_card ∈ [0.2, 0.4]

11. Composite Distance Function

distance_between(gt, pred):

11.1 Compute:
D_set
P_cov
P_extra_final
P_card_final

11.2 Combine:
D = α * D_set
  + β * P_cov
  + γ * P_extra_final
  + δ * P_card_final

11.3 Normalize:
D_final = D / (α + β + γ + δ)

Recommended:
- α = 0.4
- β = 0.3
- γ = 0.2
- δ = 0.1

Return D_final ∈ [0,1]

12. Additional Reward Components

12.1 Exact Reward

Jaccard similarity:

J = |gt ∩ enh| / |gt ∪ enh|
R_exact = 2 * J - 1

Range: [-1, 1]

12.2 Structure Reward

R_structure = 1 - penalty_invalid
    - penalty_duplicates
    - penalty_format

Where:

penalty_invalid = len(invalid_codes) / max(1, len(enh_codes))
penalty_duplicates = len(duplicate_codes) / max(1, len(enh_codes))

Clamp R_structure ∈ [-1, 1]

If parsing_success == False:
    R_structure = -1

13. Reward Function

compute_reward(gt, enh, org):

D_enh = distance_between(gt, enh)
D_org = distance_between(gt, org)

ΔD = D_org - D_enh

R_tree = ΔD

R_total = tanh(w_tree * R_tree
    + w_exact * R_exact
    + w_structure * R_structure
)

Return reward ∈ [-1,1]

Recommended:
- w_tree = 0.6
- w_exact = 0.25
- w_structure = 0.15
